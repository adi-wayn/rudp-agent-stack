# Workflow: release_preparation
description: Prepare project for release.

steps:
1. Ensure repository versioning and changelog updated.
2. Run full test suite.
3. Generate build artifacts (tar/zip).
4. Tag release in version control.
5. Create release notes summarizing:
   - Features
   - Limitations
   - Known issues
6. Update GitHub Pages/Docs folder.
