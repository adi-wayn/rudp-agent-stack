# Workflow: generate_artifacts_docs
description: Produce documentation artifacts.

steps:
1. Extract all state machines and convert them to diagrams.
2. Generate Mermaid diagrams from spec.
3. Create ASCII/txt sequence diagrams for message flows.
4. Generate README section drafts:
   - Overview
   - Protocol Specification
   - Deployment Instructions
   - Testing Guidelines
5. Create PCAP annotation guidelines.
6. Produce PDF export of documentation.
